## 📌 Project Overview
**CSS Filter Generator App** is an interactive frontend tool built using **HTML, CSS, and JavaScript**.  
It allows users to dynamically generate CSS filter effects like blur, brightness, contrast, grayscale, sepia, and more — with real-time preview and instant CSS code output.

This project demonstrates effective DOM manipulation, event handling, and real-time style updates using JavaScript.
